Convergence rates: what "fast" means

Ketan Suhaas Saichandran
optimizationconvergenceratesproofs

Builds on: Gradient descent on a quadratic · Leads to: Smoothness and strong convexity

A rate says how fast the error shrinks per step. Flip it around and it says how many steps buy a given accuracy, which is the number you actually care about.

The one move

Track one error number $e_k\ge0$ after $k$ steps, such as $f(x_k)-f^*$ or $\|x_k-x^*\|$. A rate is a bound $e_k\le r(k)$. To get iterations, set the bound $\le\varepsilon$ and isolate $k$.

$$e_k\le r(k)\le\varepsilon \quad\Longrightarrow\quad k\ge k(\varepsilon).$$

Every derivation below is this move. Throughout, $\ln$ is the natural log.

Sublinear: $C/k$ and $C/\sqrt k$

The error falls like a power of $k$. Each extra digit of accuracy multiplies the step count by 10 (or by 100).

$$\frac Ck\le\varepsilon \iff k\ge\frac C\varepsilon \qquad \text{(multiply by } k/\varepsilon\gt0).$$

$$\frac C{\sqrt k}\le\varepsilon \iff \sqrt k\ge\frac C\varepsilon \iff k\ge\frac{C^2}{\varepsilon^2} \qquad \text{(square; both sides}\gt0).$$

Example

$C=1$, $\varepsilon=10^{-6}$: $k=10^6$ steps for $1/k$, and $k=10^{12}$ for $1/\sqrt k$. Replacing $\varepsilon$ by $\varepsilon/10$ multiplies $k$ by $10$ and by $100$.

Linear: $\rho^k$

Every step multiplies the error by the same $\rho\lt1$, so every digit costs the same number of steps. "Linear" means the number of correct digits grows linearly in $k$.

$$\rho^ke_0\le\varepsilon \iff k\ln\rho\le\ln\frac{\varepsilon}{e_0} \qquad \text{(}\ln\text{ is increasing)}$$

$$\iff k\ge\frac{\ln(e_0/\varepsilon)}{\ln(1/\rho)} \qquad \text{(divide by }\ln\rho\lt0\text{: the inequality flips)}.$$

The later notes get $\rho=1-1/\kappa$. Simplify the denominator with the Taylor series of $-\ln(1-t)$, whose terms are all positive for $0\lt t\lt1$:

$$\ln\frac1\rho=-\ln\Big(1-\frac1\kappa\Big)=\frac1\kappa+\frac1{2\kappa^2}+\frac1{3\kappa^3}+\cdots\ \ge\ \frac1\kappa.$$

A bigger denominator only lowers the requirement, so

$$k\ \ge\ \kappa\,\ln\frac{e_0}{\varepsilon} \quad\text{steps are always enough.}$$

Example

$\rho=0.9$ ($\kappa=10$), $e_0=1$, $\varepsilon=10^{-6}$. Here $\ln10^6=6\ln10=13.82$ and $\ln(1/0.9)=0.1054$:

$$k\ge\frac{13.82}{0.1054}=131.1\ \Rightarrow\ 132 \text{ steps}; \qquad \kappa\text{-estimate: } 10\times13.82=138.$$

Why linear looks linear on a log plot

A log axis turns "multiply by $\rho$" into "subtract a constant", so a geometric decay becomes a straight line.

$$\ln(\rho^ke_0)=\ln e_0+k\ln\rho \qquad \text{a line in } k\text{, slope } \ln\rho\lt0.$$

$$\ln\frac Ck=\ln C-\ln k \qquad \text{slope } \tfrac{d}{dk}(-\ln k)=-\tfrac1k\to0\text{: it flattens.}$$

Quadratic convergence (below) doubles its slope every step, so it plunges.

Quadratic: $e_{k+1}\le Ce_k^2$

Each step squares the error, so the number of correct digits doubles. It only kicks in once $e_k$ is already small.

Step 1: remove $C$. Let $a_k=Ce_k$. Then

$$a_{k+1}=Ce_{k+1}\le C\cdot Ce_k^2=a_k^2.$$

Step 2: induction. Claim $a_k\le a_0^{2^k}$. True at $k=0$. If true at $k$ (squaring keeps the order since $a_k\ge0$):

$$a_{k+1}\le a_k^2\le\big(a_0^{2^k}\big)^2=a_0^{2^{k+1}}.$$

Step 3: solve for $k$. Start close enough that $a_0\le\tfrac12$, so $a_k\le2^{-2^k}$. Then $e_k=a_k/C\le\varepsilon$ holds once

$$2^{-2^k}\le C\varepsilon \iff 2^k\ge\log_2\frac1{C\varepsilon} \iff k\ge\log_2\log_2\frac1{C\varepsilon}.$$

Example

$C=1$, $e_0=\tfrac12$, $\varepsilon=10^{-6}$: $\log_2 10^6=19.9$ and $\log_2 19.9=4.3$, so $5$ steps. The errors: $\tfrac12,\ \tfrac14,\ \tfrac1{16},\ \tfrac1{256},\ 1.5\cdot10^{-5},\ 2.3\cdot10^{-10}$.

Derive it yourself

With $e_0=1$, how many steps until $e_k\le10^{-6}$ when $\rho=0.5$? When $\rho=0.98$? How many steps per digit? Compare with gradient descent on a quadratic, where $\kappa=3$ gave rate $0.5$ and $\kappa=100$ gave rate $\approx0.98$.

Solution

Use $k\ge\ln(e_0/\varepsilon)/\ln(1/\rho)$ with $\ln10^6=13.82$, and steps per digit $=\ln10/\ln(1/\rho)$, $\ln10=2.303$.

$$\rho=0.5:\quad \ln2=0.693, \qquad k\ge\frac{13.82}{0.693}=19.9\ \Rightarrow\ 20, \qquad \frac{2.303}{0.693}=3.3 \text{ per digit}.$$

$$\rho=0.98:\quad \ln\tfrac1{0.98}=0.0202, \qquad k\ge\frac{13.82}{0.0202}=684, \qquad \frac{2.303}{0.0202}=114 \text{ per digit}.$$

The exact $\kappa=100$ rate is $\rho=\tfrac{99}{101}$, with $\ln\tfrac{101}{99}=0.0200$: $691$ steps, $115$ per digit. Both match "about 3" and "about 115 steps per digit". Shortcut: $\rho=\tfrac{\kappa-1}{\kappa+1}=1-\tfrac2{\kappa+1}$, so the Taylor bound above gives $k\ge\tfrac{\kappa+1}2\ln\tfrac1\varepsilon=50.5\times13.82=698$ for $\kappa=100$.
