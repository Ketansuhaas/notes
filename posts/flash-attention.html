FlashAttention: tiling plus online softmax

Ketan Suhaas Saichandran
gpuattentionflash-attentionsoftmaxkernel-fusion

Builds on: Tiled matrix multiplication, Kernel fusion and torch.compile, Triton: programming GPUs in blocks

Attention's cost is not the math, it is the $n\times n$ score matrix round-tripping through HBM. FlashAttention never writes it: it tiles, and fixes up the softmax as it goes.

Standard attention materializes $S$

Every query meets every key, so the scores form an $n\times n$ matrix. The standard path writes it to HBM, reads it for softmax, writes $P$, reads $P$ again.

$$\underbrace{S}_{n\times n}=\frac{QK^T}{\sqrt d},\qquad P=\operatorname{softmax}_{\text{row}}(S),\qquad \underbrace{O}_{n\times d}=PV.$$

Example: $n=8192$, $d=128$, BF16, one head

$Q,K,V,O$$4\times2$ MB
$S$ or $P$$134$ MB each
HBM traffic for $S,P$ (write, read, write, read)$\approx540$ MB

Memory grows as $O(n^2)$, and the softmax is a memory-bound pass over it.

Online softmax

Softmax needs the row's max and sum over all keys. You can get both in one streaming pass: keep a running max $m$ and sum $\ell$, and rescale the old totals whenever the max grows.

For one query row, a new block of scores $s_j$ with values $v_j$:

$$m'=\max\!\big(m,\ \max_j s_j\big),\qquad \ell'=e^{m-m'}\,\ell+\sum_j e^{s_j-m'},$$ $$o'=e^{m-m'}\,o+\sum_j e^{s_j-m'}\,v_j.$$

Start at $m=-\infty$, $\ell=0$, $o=0$. Output $O=o/\ell$.

Check: scores $(1,2\mid3,0)$, values $(1,0\mid2,4)$

$m$$\ell$$o$
Block 1$2$$e^{-1}+1=1.368$$e^{-1}\cdot1=0.368$
Block 2 (rescale $e^{2-3}=0.368$)$3$$0.503+1+e^{-3}=1.553$$0.135+2+4e^{-3}=2.334$
Direct softmax$3$$e^{-2}+e^{-1}+1+e^{-3}=1.553$$2.334$

Both give $O=2.334/1.553=1.503$. Exact, not approximate.

Tiling: $S$ only exists one tile at a time

Each program owns a block of query rows and keeps $Q_i$, $m$, $\ell$, $o$ in SRAM. It streams $K_j,V_j$ blocks past, computing one score tile, folding it in, discarding it.

Derive it yourself

Split a row's scores into blocks $A$ and $B$ with $m_A=\max_A s_j$, $\ell_A=\sum_{A}e^{s_j-m_A}$ (same for $B$). Show that $m=\max(m_A,m_B)$ and $\ell=e^{m_A-m}\ell_A+e^{m_B-m}\ell_B$ give the exact softmax normalizer.

Solution

$$e^{m_A-m}\,\ell_A=\sum_{A}e^{m_A-m}\,e^{s_j-m_A}=\sum_{A}e^{s_j-m}.$$

Same for $B$, so $\ell=\sum_{A\cup B}e^{s_j-m}=e^{-m}\sum_{\text{all}}e^{s_j}$.

Then $e^{s_j-m}/\ell=e^{s_j}/\sum_k e^{s_k}$: exactly softmax. Since $m$ is the true max, every exponent is $\le0$, so nothing overflows. The same factor $e^{m_A-m}$ rescales $o$, so $o/\ell$ is exact too.
