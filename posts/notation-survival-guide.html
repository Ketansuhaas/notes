Reading the notation in papers

Ketan Suhaas Saichandran
notationfoundations

Builds on: nothing, start here · Leads to: Four views of matrix multiplication, Expectation and variance algebra

An equation is a compressed sentence. Ask three things: what shape is each symbol, what is random, what is optimized.

Shapes

Every symbol is a box of numbers. Write its shape underneath it.

$$ \underbrace{X}_{n\times d}=\begin{pmatrix}-\,x_1^T-\\\vdots\\-\,x_n^T-\end{pmatrix}, \quad \underbrace{x_i}_{d\times1}\ (\text{a column}), \quad X_{ij}=\text{point } i,\ \text{feature } j. $$

Symbols

$a:=b$defines $a$
$a\propto b$equal up to a constant you can ignore
$X\sim p$, $\ \overset{\text{iid}}{\sim}$drawn from $p$; independent draws from the same $p$
$\mathbb{E}_{x\sim p}[f(x)]$average of $f$; the subscript is what's random
$\min_\theta L$ vs $\operatorname*{arg\,min}_\theta L$best value vs. the $\theta$ that achieves it
$\nabla_\theta L$gradient in $\theta$ only
$\|x\|_2$, $\langle x,y\rangle$length, dot product $x^Ty$
$x\odot y$, $\ xy^T$elementwise product, outer product
$\operatorname{tr}A$, $\operatorname{diag}(v)$, $\mathbb{1}[\cdot]$sum of diagonal, diagonal matrix, 1 if true else 0
$\hat\theta$, $\theta^\star$, $\bar x$, $\tilde x$estimate, optimum, mean, noisy version

One real line, decoded

Read from the inside out.

$$ \theta^\star=\operatorname*{arg\,min}_\theta\ \underbrace{\mathbb{E}_{(x,y)\sim p_{\text{data}}}\big[\underbrace{-\log p_\theta(y\mid x)}_{\text{surprise at the true label}}\big]}_{\text{averaged over real data}}+\underbrace{\lambda\|\theta\|_2^2}_{\text{weight decay}}. $$

"Find the weights that give the correct labels high probability, keeping weights small."

Derive it yourself

Give every shape, then say it in words ($x_i\in\mathbb{R}^d$, $y_i\in\mathbb{R}^k$): $\ \mathcal{L}(W)=\frac1n\sum_i\|Wx_i-y_i\|_2^2$.

Solution

$W$ is $k\times d$, $Wx_i-y_i$ is $k\times1$, $\mathcal{L}$ is a scalar. "Mean squared error of a linear map $\mathbb{R}^d\to\mathbb{R}^k$."
