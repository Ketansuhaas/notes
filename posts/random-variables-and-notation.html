Probability notation and random variables

Builds on: Reading the notation in papers · Leads to: Expectation and variance algebra, Common distributions, Lebesgue measure and KL divergence

A handful of symbols carry all of probability in papers. Read each one precisely and the formulas stop being cryptic.

Random variable vs. realization

$X$ is a number not yet seen; $x$ is one already seen.

$$X:\Omega\to\mathbb{R}^d, \qquad x=X(\omega) \ \text{ for one outcome } \omega.$$

Example

Coin: $\Omega=\{H,T\}$, $X(H)=1$, $X(T)=0$. On today's flip, $x=1$.

$P$ eats events, $p$ eats values

$P$ measures a set of outcomes. $p$ measures how concentrated probability is at a single value.

$P(x)$ alone is ill-formed: $x$ is a number, not an event. Write $P(X=x)$.

Example

$X\sim\text{Unif}[0,\tfrac12]$: $p(x)=2$ on the interval, yet $P(X=\tfrac14)=0$ and $P(X\le\tfrac14)=2\cdot\tfrac14=\tfrac12$.

Random vectors: joint, marginal, conditional

$p$ takes the whole vector and returns one number. Three moves shrink a joint into smaller pieces.

$$\underbrace{x}_{d\times1}=(x_1,\dots,x_d), \qquad \underbrace{p(x)}_{\text{scalar}}=p(x_1,\dots,x_d).$$

marginal$p(x)=\int p(x,y)\,dy$sum a variable away
conditional$p(y\mid x)=\dfrac{p(x,y)}{p(x)}$restrict, renormalize
independence$p(x,y)=p(x)\,p(y)$conditioning changes nothing

Chain rule (any ordering), the engine of autoregressive models:

$$p(x_1,\dots,x_n)=\prod_{i=1}^np(x_i\mid x_{\lt i}).$$

Example

Two coins, $x_2$ copies $x_1$: $p(x_1,x_2)=p(x_1)\,p(x_2\mid x_1)=\tfrac12\cdot1$ if $x_1=x_2$, else $0$. Not independent ($\tfrac12\ne\tfrac14$), but the chain rule holds.

Expectation: name the distribution

The subscript says whose randomness you average over. Once two distributions appear, never drop it.

$$\mathbb{E}_{x\sim p}[f(x)]=\sum_xp(x)f(x) \quad\text{or}\quad \int p(x)f(x)\,dx.$$

Example

$\mathbb{E}_{x\sim p}[-\log q(x)]$ (cross-entropy) and $\mathbb{E}_{x\sim q}[-\log q(x)]$ (entropy of $q$) differ only in the subscript.

The data distribution

There is one unknown true distribution; the dataset is a few samples of it. Every model approximates some piece.

$$x_i\overset{\text{iid}}{\sim}p_{\text{data}}(x) \quad\text{or}\quad (x_i,y_i)\overset{\text{iid}}{\sim}p_{\text{data}}(x,y).$$

classifierapproximates $p_{\text{data}}(y\mid x)$
generative modelapproximates $p_{\text{data}}(x)$

Derive it yourself

Using only the definitions above, derive Bayes' rule: $p(x\mid y)=\dfrac{p(y\mid x)\,p(x)}{\sum_{x'}p(y\mid x')\,p(x')}$.

Solution

Conditional, both ways: $p(x,y)=p(y\mid x)\,p(x)=p(x\mid y)\,p(y)$. Divide by $p(y)$. Marginalize the denominator: $p(y)=\sum_{x'}p(x',y)=\sum_{x'}p(y\mid x')\,p(x')$.
