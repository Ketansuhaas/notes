Rank, subspaces, and projections

Ketan Suhaas Saichandran

Builds on: Four views of matrix multiplication, Lines, planes, and spheres in $\mathbb{R}^n$ · Leads to: Eigenvalues, eigenvectors, and defectiveness, Singular value decomposition

$A$ maps $\mathbb{R}^n\to\mathbb{R}^m$. Four subspaces say what it reaches, what it kills, and how close it gets otherwise.

Subspaces, span, basis

A subspace is a flat slice through the origin. A span is everywhere some vectors can reach; a basis reaches it with no redundancy.

Subspaceclosed under $+$ and scaling, contains $0$
Span$\operatorname{span}(v_1,\dots,v_k)=\{c_1v_1+\cdots+c_kv_k\}$
Basisindependent spanning set (drop one and the span shrinks)
Dimensionsize of any basis

Example

$(1,0,0),(0,1,0),(1,1,0)$ span the $xy$-plane. Any two form a basis, so $\dim=2$.

Rank

How many independent directions $A$ can output. $Ax$ mixes columns (view 2), so rank counts the genuinely different columns.

$$\operatorname{rank}A=\dim C(A)=\dim C(A^T)=\#\text{pivots}, \qquad \underbrace{A}_{m\times n}=\underbrace{B}_{m\times r}\underbrace{C}_{r\times n}\ (\text{an } r\text{-dim bottleneck}).$$

Row-reduced (columns permuted if needed), the bottleneck is an identity block:

$$R=\begin{pmatrix}I_r&F\\0&0\end{pmatrix}:$$ $$I_r=\text{pivot columns},\ \ F=\text{free columns as mixes of pivots},\ \ 0=\text{dependent rows}.$$

Example: rank 1 = one column times one row

$$\underbrace{\begin{pmatrix}1&2\\2&4\\3&6\end{pmatrix}}_{3\times2}=\underbrace{\begin{pmatrix}1\\2\\3\end{pmatrix}}_{3\times1}\underbrace{\begin{pmatrix}1&2\end{pmatrix}}_{1\times2}.$$

The four fundamental subspaces

$C(A)$: everywhere $Ax$ can reach. $N(A)$: everything $A$ crushes to $0$. Each has a perpendicular partner from $A^T$.

Column space $C(A)$in $\mathbb{R}^m$$\dim r$
Null space $N(A)=\{x:Ax=0\}$in $\mathbb{R}^n$$\dim n-r$
Row space $C(A^T)$in $\mathbb{R}^n$$\dim r$
Left null space $N(A^T)$in $\mathbb{R}^m$$\dim m-r$

$$N(A)\perp C(A^T), \qquad N(A^T)\perp C(A). \qquad (Ax=0 \text{ says every row of } A \text{ is } \perp x.)$$

Example: the rank-1 matrix above

$C(A)=\operatorname{span}(1,2,3)$, $C(A^T)=\operatorname{span}(1,2)$, $N(A)=\operatorname{span}(2,-1)$, $N(A^T)$ = the plane $x+2y+3z=0$. Check $(1,2)\cdot(2,-1)=0$. ✓

Solving $Ax=b$

Solvable iff $b\in C(A)$. Unique iff $N(A)=\{0\}$. Shape and rank decide which.

Tall, $m\gt n$, $r=n$$R=\begin{pmatrix}I_n\\0\end{pmatrix}$$N(A)=\{0\}$: at most one solution
Wide, $m\lt n$, $r=m$$R=\begin{pmatrix}I_m&F\end{pmatrix}$$C(A)=\mathbb{R}^m$: always solvable, $n-m$ free variables
Square, $r=n$$R=I_n$unique $x=A^{-1}b$
Rank-deficientzero rows and $F$none or infinitely many

Example: rank-1 $A$ above

$b=(1,2,3)\in C(A)$: $x=(1,0)+t(2,-1)$, infinitely many. $b=(1,0,0)\notin C(A)$: no solution.

Projection

If $b$ is out of reach, take the closest reachable point: the one whose error is perpendicular to everything reachable.

$$e=b-A\hat x\perp C(A) \iff A^T(b-A\hat x)=0 \iff A^TA\,\hat x=A^Tb.$$

With independent columns ($A$ tall, rank $n$):

$$\hat x=\underbrace{(A^TA)^{-1}A^T}_{n\times m}\,\underbrace{b}_{m\times1}, \qquad P=\underbrace{A}_{m\times n}\underbrace{(A^TA)^{-1}}_{n\times n}\underbrace{A^T}_{n\times m}\ \ (m\times m,\ \text{rank } n).$$

Onto a single line $a$: $P=\dfrac{aa^T}{a^Ta}$.

Example

$a=(1,1)$, $b=(2,0)$: $\hat x=\tfrac{a^Tb}{a^Ta}=1$, $p=(1,1)$, $e=(1,-1)\perp a$. ✓

The big picture

$A$ sees only the row-space part of its input and reaches only the column space. The null spaces are its blind spots.

$$\mathbb{R}^n=C(A^T)\oplus N(A), \qquad \mathbb{R}^m=C(A)\oplus N(A^T).$$

$$Ax=A(x_{\text{row}}+x_{\text{null}})=Ax_{\text{row}}, \qquad b=\underbrace{b_{\text{col}}}_{\text{reachable}}+\underbrace{b_\perp}_{\text{never reached}}.$$

$A$ maps row space one-to-one onto column space; least squares solves $Ax=b_{\text{col}}$.

Example: rank-1 $A$, $x=(1,0)$

$x_{\text{row}}=\tfrac15(1,2)$, $x_{\text{null}}=\tfrac25(2,-1)$. Then $Ax_{\text{row}}=\tfrac15(5,10,15)=(1,2,3)=Ax$. ✓

Derive it yourself

Prove $N(A^TA)=N(A)$. Conclude that $A^TA$ is invertible exactly when $A$ has independent columns.

Solution

$Ax=0\Rightarrow A^TAx=0$. Conversely, $A^TAx=0\Rightarrow x^TA^TAx=\|Ax\|^2=0\Rightarrow Ax=0$. Same null space, so the $n\times n$ matrix $A^TA$ is invertible $\iff N(A)=\{0\}\iff\operatorname{rank}A=n$.
