Inside a GPU: SMs, warps, and memory

A GPU is ~100 copies of one processor (the SM). Each runs threads in groups of 32 that share one instruction, and all of them pull data through a stack of memories, small and fast on top, big and slow below.

The SM: the unit that repeats

A streaming multiprocessor (SM) has its own lanes, tensor cores, registers and fast scratch memory. The chip is many SMs plus shared L2 and HBM.

Warps: 32 threads, one instruction

Threads run in warps of 32 that execute the same instruction at the same time on different data (SIMT). If they disagree on a branch, the warp runs both sides, masking off the threads that did not take each one.

if (threadIdx.x % 2 == 0) y = a(x);   // odd threads masked, wait
else                      y = b(x);   // even threads masked, wait

$$\text{divergent warp: } t=t_a+t_b, \qquad \text{uniform warp: } t=t_a \text{ or } t_b.$$

Example

if (threadIdx.x < 32) keeps whole warps together: no divergence. if (threadIdx.x % 2) splits every warp in half.

The memory hierarchy

Fast memory is small and close to the lanes; big memory is far and slow. Good kernels fetch from HBM once and reuse the data from higher up.

Coalescing: read whole sectors

HBM delivers 32-byte sectors, never single values. If a warp's threads read consecutive addresses, their loads merge into a few full sectors; scattered reads each drag in a sector for a few useful bytes.

$$\text{thread } t \text{ reads } x[t]:\quad 32\times4\text{ B}=128\text{ B}=4\text{ sectors, every byte used}.$$

Work it out yourself

A warp reads one column of a row-major $1024\times1024$ fp32 matrix: thread $t$ reads A[t*1024 + j]. Coalesced? How many sectors, and what fraction of the fetched bytes is used?

Solution

No. Neighbouring threads are $1024\cdot4=4096$ B apart, so each lands in its own sector: $32$ sectors ($1024$ B) for $128$ useful bytes. Efficiency $1/8$, i.e. $8\times$ the traffic of reading a row.

Fix: let consecutive threads walk along a row (A[i*1024 + t]), or stage the tile through shared memory and transpose it there.
