Gradients, Jacobians, and Hessians

Ketan Suhaas Saichandran

Builds on: Four views of matrix multiplication, Quadratic forms and positive definiteness · Leads to: Taylor expansion in many variables, Matrix calculus with differentials, Backpropagation via Jacobian-vector products

A derivative is a matrix that turns a small nudge of the input into the change of the output. Its shape is always (outputs) $\times$ (inputs).

$f:\mathbb{R}^n\to\mathbb{R}$gradient $\nabla f$$n\times1$ (a column, by convention)
$g:\mathbb{R}^n\to\mathbb{R}^m$Jacobian $J$$m\times n$
$\nabla f:\mathbb{R}^n\to\mathbb{R}^n$Hessian $H$$n\times n$

The gradient

Stack every partial derivative into a vector shaped like $x$. It points uphill, perpendicular to the level curves.

$$\underbrace{\nabla f(x)}_{n\times1}=\begin{pmatrix}\partial f/\partial x_1\\\vdots\\\partial f/\partial x_n\end{pmatrix}, \qquad f(x+\epsilon v)\approx f(x)+\epsilon\,\underbrace{\nabla f^T}_{1\times n}\underbrace{v}_{n\times1}.$$

Example

$f=x_1^2+x_1x_2+x_2^2=\tfrac12x^TAx$ with the running $A=\begin{pmatrix}2&1\\1&2\end{pmatrix}$: $\ \nabla f=(2x_1+x_2,\ x_1+2x_2)$, so $\nabla f(1,1)=(3,3)$.

Steepest ascent

The slope along $v$ is largest when $v$ lines up with $\nabla f$. That is why gradient descent steps along $-\nabla f$.

$$\|v\|=1: \qquad D_vf=\nabla f^Tv=\|\nabla f\|\cos\theta\ \in\ \big[-\|\nabla f\|,\ \|\nabla f\|\big] \quad (\text{Cauchy-Schwarz}).$$

Example: at $(1,1)$, $\nabla f=(3,3)$

$v=\tfrac1{\sqrt2}(1,1)$, along $\nabla f$slope $3\sqrt2\approx4.24$, the max
$v=(1,0)$slope $3$
$v=\tfrac1{\sqrt2}(1,-1)$, along the level curveslope $0$

The Jacobian

With several outputs, stack one gradient per output as rows. $J$ is the best linear approximation of $g$ near $x$.

$$\underbrace{J}_{m\times n}=\begin{pmatrix}-\ \nabla g_1^T\ -\\\vdots\\-\ \nabla g_m^T\ -\end{pmatrix}, \quad J_{ij}=\frac{\partial g_i}{\partial x_j}, \qquad g(x+\Delta)\approx g(x)+\underbrace{J}_{m\times n}\underbrace{\Delta}_{n\times1}.$$

Rows are outputs, columns are inputs. For a scalar $f$, $J$ is the row $\nabla f^T$.

Example

$$g(x)=\begin{pmatrix}x_1+x_2\\x_1x_2\\x_1^2\end{pmatrix}: \qquad \underbrace{J}_{3\times2}=\begin{pmatrix}1&1\\x_2&x_1\\2x_1&0\end{pmatrix}, \qquad J(1,1)=\begin{pmatrix}1&1\\1&1\\2&0\end{pmatrix}.$$

Chain rule: Jacobians multiply

Compose functions and their Jacobians multiply, in the same order. The shapes chain like any matrix product; this is backpropagation.

$$k=h\circ g: \qquad \underbrace{J_k}_{p\times n}=\underbrace{J_h}_{p\times m}\,\underbrace{J_g}_{m\times n}.$$

JVP $Jv$ ($m\times1$)push an input nudge forwardforward mode
VJP $u^TJ$ ($1\times n$)pull an output sensitivity backreverse mode (backprop)

A scalar loss has $p=1$: reverse mode carries one row backward and gets all $n$ derivatives in one pass.

Example: $g$ as above, $h(y)=y_1+y_2+y_3$

$$J_k(1,1)=\underbrace{(1,1,1)}_{1\times3}\underbrace{\begin{pmatrix}1&1\\1&1\\2&0\end{pmatrix}}_{3\times2}=(4,\ 2).$$

Direct: $k=x_1+x_2+x_1x_2+x_1^2$ has $\nabla k(1,1)=(1+1+2,\ 1+1)=(4,2)$. ✓

The Hessian

The gradient is itself a map $\mathbb{R}^n\to\mathbb{R}^n$; its Jacobian is the Hessian, which measures curvature.

$$\underbrace{H}_{n\times n}=J_{\nabla f}, \quad H_{ij}=\frac{\partial^2f}{\partial x_i\partial x_j}=H_{ji}\ \ (\text{smooth } f), \qquad \underbrace{v^T}_{1\times n}\underbrace{H}_{n\times n}\underbrace{v}_{n\times1}=\text{curvature along } v.$$

Example

The Jacobian of $\nabla f=(2x_1+x_2,\ x_1+2x_2)$ is $H=\begin{pmatrix}2&1\\1&2\end{pmatrix}=A$: positive definite, so $f$ is a bowl.

Next: $\nabla f$ and $H$ combine into a local bowl (Taylor expansion).

Derive it yourself

$W$ is $m\times n$ and $k(x)=\tfrac12\|Wx\|^2$. Write $k=h\circ g$ with $g(x)=Wx$, $h(y)=\tfrac12\|y\|^2$, and use the chain rule to find $\nabla k$ and the Hessian. Check every shape.

Solution

$J_g=W$ ($m\times n$), $J_h=y^T=(Wx)^T$ ($1\times m$). So $J_k=x^TW^TW$ ($1\times n$) and $\nabla k=W^TWx$ ($n\times1$). Its Jacobian is $H=W^TW$ ($n\times n$), which is positive semidefinite: $k$ is a bowl, possibly with flat valleys along $N(W)$.
