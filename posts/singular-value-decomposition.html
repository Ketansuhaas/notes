Singular value decomposition

Ketan Suhaas Saichandran
linear-algebraeigenvaluessvdmatrix-factorization

Builds on: Rank, subspaces, and projections, The spectral theorem, Quadratic forms and positive definiteness · Leads to: Principal component analysis

Every matrix, any shape, is a rotation, then a stretch along the axes, then another rotation. Below, every piece is derived, nothing assumed.

The goal

Find perpendicular input directions $v_i$ that $A$ sends to perpendicular output directions $u_i$, only stretching them by $\sigma_i\ge0$.

$$Av_i=\sigma_iu_i, \qquad v_1,\dots,v_n \text{ orthonormal in } \mathbb{R}^n, \qquad u_1,\dots,u_m \text{ orthonormal in } \mathbb{R}^m.$$

If we find them, the matrix form follows by stacking the columns (view 2 of matrix multiplication):

$$ A\underbrace{\begin{pmatrix}\vert&&\vert\\v_1&\cdots&v_n\\\vert&&\vert\end{pmatrix}}_{V,\ n\times n} =\begin{pmatrix}\vert&&\vert\\\sigma_1u_1&\cdots&\sigma_nu_n\\\vert&&\vert\end{pmatrix} =\underbrace{U}_{m\times m}\,\underbrace{\Sigma}_{m\times n}. $$

$V$ is square with orthonormal columns, so $VV^T=I$. Multiply both sides on the right by $V^T$:

$$\boxed{\ \underbrace{A}_{m\times n}=\underbrace{U}_{m\times m}\,\underbrace{\Sigma}_{m\times n}\,\underbrace{V^T}_{n\times n}\ }$$

$\Sigma$ has $\sigma_i$ at position $(i,i)$ and zeros elsewhere. The rest of this note finds the $v_i$, $\sigma_i$, $u_i$.

Step 1: look at $A^TA$

The length of an output is all we need to find the stretches, and $A^TA$ is exactly the matrix that measures output length.

$$\|Ax\|^2=(Ax)^T(Ax)=x^T\,\underbrace{A^TA}_{n\times n}\,x.$$

$A^TA$ is symmetric, $(A^TA)^T=A^T(A^T)^T=A^TA$, so by the spectral theorem it has orthonormal eigenvectors $v_1,\dots,v_n$ with real eigenvalues $\lambda_i$. These $v_i$ are our input directions. Each $\lambda_i\ge0$, because

$$\lambda_i=\lambda_i\,v_i^Tv_i=v_i^T(A^TAv_i)=\|Av_i\|^2\ge0.$$

Step 2: the stretch is $\sigma_i=\sqrt{\lambda_i}$

The line above already says how long $Av_i$ is. Name that length $\sigma_i$.

$$\|Av_i\|^2=\lambda_i \quad\Rightarrow\quad \sigma_i:=\|Av_i\|=\sqrt{\lambda_i}.$$

Order them so $\sigma_1\ge\sigma_2\ge\cdots\ge0$.

Step 3: the outputs stay perpendicular

Divide each output by its length to get a unit vector $u_i$. The surprise is that these are automatically perpendicular.

For $\sigma_i\gt0$ define $u_i:=Av_i/\sigma_i$, so $Av_i=\sigma_iu_i$ holds by construction. Their dot products:

$$ u_i^Tu_j=\frac{(Av_i)^T(Av_j)}{\sigma_i\sigma_j}=\frac{v_i^T(A^TAv_j)}{\sigma_i\sigma_j}=\frac{\lambda_j\,v_i^Tv_j}{\sigma_i\sigma_j}=\begin{cases}\lambda_i/\sigma_i^2=1 & i=j\\0 & i\ne j\end{cases} $$

If $\sigma_i=0$ then $\|Av_i\|=0$, so $Av_i=0=0\cdot u_i$ for any $u_i$. Complete the $u$'s to an orthonormal basis of $\mathbb{R}^m$ any way you like. Every requirement of the goal now holds, so every matrix has an SVD.

Step 4: the same thing from the other side

The $u_i$ are eigenvectors of $AA^T$, so you can start from whichever of $A^TA$, $AA^T$ is smaller.

Substitute $A=U\Sigma V^T$ and use $V^TV=I$:

$$AA^T=U\Sigma V^T\,V\Sigma^TU^T=U\,(\Sigma\Sigma^T)\,U^T, \qquad \Sigma\Sigma^T=\operatorname{diag}(\sigma_1^2,\dots).$$

That is a spectral decomposition, so $AA^Tu_i=\sigma_i^2u_i$. To go back from $u_i$ to $v_i$, apply $A^T$ to $Av_i=\sigma_iu_i$:

$$A^TAv_i=\sigma_iA^Tu_i \quad\Rightarrow\quad \sigma_i^2v_i=\sigma_iA^Tu_i \quad\Rightarrow\quad v_i=\frac{A^Tu_i}{\sigma_i}.$$

Worked example, every step

$$A=\begin{pmatrix}1&0&1\\0&1&1\end{pmatrix} \quad (2\times3).$$

1. Smaller Gram matrix. $AA^T$ is $2\times2$ (versus $3\times3$ for $A^TA$). Each entry is a dot product of two rows of $A$:

$$AA^T=\begin{pmatrix}1+0+1&0+0+1\\0+0+1&0+1+1\end{pmatrix}=\begin{pmatrix}2&1\\1&2\end{pmatrix}.$$

2. Its eigenvalues. $\det(AA^T-\lambda I)=(2-\lambda)^2-1=0$ gives $\lambda=3,1$, so $\sigma_1=\sqrt3$, $\sigma_2=1$.

3. Its eigenvectors are the $u_i$.

$$\lambda=3:\ \begin{pmatrix}-1&1\\1&-1\end{pmatrix}u=0\Rightarrow u_1=\tfrac1{\sqrt2}\begin{pmatrix}1\\1\end{pmatrix}; \qquad \lambda=1:\ \begin{pmatrix}1&1\\1&1\end{pmatrix}u=0\Rightarrow u_2=\tfrac1{\sqrt2}\begin{pmatrix}1\\-1\end{pmatrix}.$$

4. The $v_i$ from $v_i=A^Tu_i/\sigma_i$.

$$v_1=\frac{1}{\sqrt3}\cdot\frac{1}{\sqrt2}\begin{pmatrix}1&0\\0&1\\1&1\end{pmatrix}\begin{pmatrix}1\\1\end{pmatrix}=\tfrac1{\sqrt6}\begin{pmatrix}1\\1\\2\end{pmatrix}, \qquad v_2=\frac11\cdot\frac1{\sqrt2}\begin{pmatrix}1\\-1\\0\end{pmatrix}.$$

5. The last input direction. $\sigma_3=0$, so $v_3$ solves $Av=0$: $x_1+x_3=0$, $x_2+x_3=0$, giving $v_3=\tfrac1{\sqrt3}(-1,-1,1)$.

6. Check. $Av_1=\tfrac1{\sqrt6}(1+2,\ 1+2)=\tfrac{3}{\sqrt6}(1,1)=\sqrt3\cdot\tfrac1{\sqrt2}(1,1)=\sigma_1u_1$. ✓ Also $v_1\cdot v_2=0$, $v_1\cdot v_3=\tfrac{-1-1+2}{\sqrt{18}}=0$. ✓

The four subspaces fall out

Read each subspace off the construction; nothing new is needed.

$Av_i=0$ for $i\gt r$ (the zero $\sigma$'s), and there are $n-r=\dim N(A)$ of them, so they span $N(A)$. Next, write $x$ in the $v$ basis and apply $A$:

$$x=\sum_i(v_i^Tx)\,v_i \quad\Rightarrow\quad Ax=\sum_{i\le r}\sigma_i\,(v_i^Tx)\,u_i.$$

Every output is a mix of $u_1,\dots,u_r$, so they span $C(A)$. The rest follows by perpendicularity:

first $r$ columnsremaining columns
$V$ (input, $\mathbb{R}^n$)$C(A^T)$, since it is $\perp N(A)$$N(A)$
$U$ (output, $\mathbb{R}^m$)$C(A)$$N(A^T)$, since it is $\perp C(A)$

So $\operatorname{rank}A=r=$ the number of nonzero $\sigma_i$. Example: $r=2$, and $v_3$ spans $N(A)$.

Rank-one pieces and the best approximation

The SVD is a sum of rank-one layers, biggest stretch first. Dropping the small layers costs exactly their $\sigma^2$.

Apply view 4 (outer products) to $(U\Sigma)V^T$: column $i$ of $U\Sigma$ is $\sigma_iu_i$ and row $i$ of $V^T$ is $v_i^T$, so

$$A=\sum_{i=1}^r\sigma_i\,\underbrace{u_i}_{m\times1}\underbrace{v_i^T}_{1\times n}, \qquad A_k:=\sum_{i\le k}\sigma_iu_iv_i^T.$$

The error $A-A_k=\sum_{i\gt k}\sigma_iu_iv_i^T$. The layers are orthonormal as matrices, $\operatorname{tr}\big((u_iv_i^T)^T u_jv_j^T\big)=(u_i^Tu_j)(v_i^Tv_j)=0$ for $i\ne j$ and $1$ for $i=j$, so lengths add like Pythagoras:

$$\|A-A_k\|_F^2=\sum_{i\gt k}\sigma_i^2.$$

No rank-$k$ matrix $B$ does better (Eckart-Young), shown here for the largest-stretch norm $\|M\|_2=\max_{\|x\|=1}\|Mx\|$. $B$ has rank $k$, so its null space has dimension $n-k$. It must meet the $(k+1)$-dimensional span of $v_1,\dots,v_{k+1}$ (the dimensions add to more than $n$). Take a unit $w$ in both. Then $Bw=0$ and

$$\|(A-B)w\|^2=\|Aw\|^2=\sum_{i\le k+1}\sigma_i^2(v_i^Tw)^2\ \ge\ \sigma_{k+1}^2\sum_{i\le k+1}(v_i^Tw)^2=\sigma_{k+1}^2=\|A-A_k\|_2^2.$$

Example

$$ \sigma_1u_1v_1^T=\sqrt3\cdot\tfrac{1}{\sqrt2}\cdot\tfrac1{\sqrt6}\begin{pmatrix}1\\1\end{pmatrix}\begin{pmatrix}1&1&2\end{pmatrix}=\tfrac12\begin{pmatrix}1&1&2\\1&1&2\end{pmatrix},\qquad \sigma_2u_2v_2^T=\tfrac12\begin{pmatrix}1&-1&0\\-1&1&0\end{pmatrix}. $$

Adding them gives $\begin{pmatrix}1&0&1\\0&1&1\end{pmatrix}=A$. ✓ Keeping only the first leaves error $\|\sigma_2u_2v_2^T\|_F^2=\tfrac14(1+1+1+1)=1=\sigma_2^2$. ✓

The pseudoinverse

Rotate into the SVD axes, where least squares splits into one easy equation per axis. Solve each, set the free ones to zero, rotate back.

Let $y=V^Tx$ and $c=U^Tb$. Rotations keep lengths, so

$$\|Ax-b\|^2=\|U\Sigma V^Tx-b\|^2=\|\Sigma y-c\|^2=\sum_{i\le r}(\sigma_iy_i-c_i)^2+\sum_{i\gt r}c_i^2.$$

The first sum is zero when $y_i=c_i/\sigma_i$. The last sum doesn't involve $y$, and $y_i$ for $i\gt r$ doesn't change the error, so the shortest choice ($\|x\|=\|y\|$) sets them to $0$:

$$y=\Sigma^+c, \quad \Sigma^+_{ii}=\begin{cases}1/\sigma_i&\sigma_i\gt0\\0&\text{else}\end{cases} \quad\Rightarrow\quad x^+=V\,\Sigma^+\,U^Tb=:\underbrace{A^+}_{n\times m}b.$$

Example

$b=(1,1)$: $c=U^Tb=(\sqrt2,0)$, so $y=(\sqrt2/\sqrt3,\ 0,\ 0)$ and $x^+=\sqrt{\tfrac23}\,v_1=\tfrac13(1,1,2)$. Check: $Ax^+=\tfrac13(3,3)=(1,1)$. ✓

Derive it yourself

Show $\max_{\|x\|=1}\|Ax\|=\sigma_1$, reached at $x=v_1$. (The largest stretch of $A$ is its top singular value.)

Solution

Write $x=\sum_ic_iv_i$ with $\sum_ic_i^2=1$ ($V$ is an orthonormal basis; set $\sigma_i=0$ for $i\gt r$). Then $\|Ax\|^2=x^TA^TAx=\sum_i\sigma_i^2c_i^2\le\sigma_1^2\sum_ic_i^2=\sigma_1^2$, with equality at $c=(1,0,\dots)$, i.e. $x=v_1$. Example: $\|Av_1\|=\sqrt3$.
