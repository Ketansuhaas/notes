Backpropagation via Jacobian-vector products

Ketan Suhaas Saichandran
deep-learninggradientsbackpropagationjacobianrank

Builds on: Gradients, Jacobians, and Hessians, Matrix calculus with differentials · Leads to: Automatic differentiation, Weight initialization

Backprop is the chain rule evaluated right to left. Start from the loss's gradient (a row) and multiply by one small Jacobian per layer, never forming the full product.

Setup

Each layer is a linear map, then an elementwise squash. Two local Jacobians: $W_\ell$, and a diagonal (unit $i$ depends only on input $i$).

$$ h_0=x,\quad \underbrace{z_\ell}_{n_\ell\times1}=\underbrace{W_\ell}_{n_\ell\times n_{\ell-1}}\underbrace{h_{\ell-1}}_{n_{\ell-1}\times1}+b_\ell,\quad h_\ell=\sigma(z_\ell),\quad \text{loss } \mathcal L(h_L). $$

$$\frac{\partial z_\ell}{\partial h_{\ell-1}}=W_\ell, \qquad \frac{\partial h_\ell}{\partial z_\ell}=\operatorname{diag}\big(\sigma'(z_\ell)\big).$$

The backward recursion

$g_\ell=\partial\mathcal L/\partial h_\ell$ is a row: how much the loss cares about each unit. One step back means multiplying by that layer's two Jacobians, on the right.

$$ \underbrace{g_{\ell-1}}_{1\times n_{\ell-1}}=g_\ell\,\operatorname{diag}\big(\sigma'(z_\ell)\big)\,W_\ell=\underbrace{g_{z_\ell}}_{1\times n_\ell}\underbrace{W_\ell}_{n_\ell\times n_{\ell-1}}, \qquad g_{z_\ell}:=g_\ell\odot\sigma'(z_\ell)^T. $$

Start: $g_L=(h_L-y)^T$ for $\mathcal L=\tfrac12\|h_L-y\|^2$. Each step is a row times a matrix: a vector-Jacobian product.

Weight gradient: error times input

Exactly the linear layer from Matrix calculus: an outer product of the error arriving at $z_\ell$ and the input that fed it. An input that was $0$ gets no gradient on its weights.

$$ d\mathcal L=g_{z_\ell}\,dW_\ell\,h_{\ell-1}=\operatorname{tr}\big(h_{\ell-1}\,g_{z_\ell}\,dW_\ell\big) \ \Rightarrow\ \underbrace{\nabla_{W_\ell}\mathcal L}_{n_\ell\times n_{\ell-1}}=\underbrace{\delta_\ell}_{n_\ell\times1}\underbrace{h_{\ell-1}^T}_{1\times n_{\ell-1}}, \quad \nabla_{b_\ell}\mathcal L=\delta_\ell, $$

with $\delta_\ell:=g_{z_\ell}^T$, the same error written as a column.

Example: one ReLU layer

$x=\begin{pmatrix}1\\2\end{pmatrix}$, $W=\begin{pmatrix}1&-1\\1&1\end{pmatrix}$, $b=0$, $y=\begin{pmatrix}0\\1\end{pmatrix}$.

Forward$z=(-1,\,3)$, $h=(0,\,3)$, $\mathcal L=\tfrac12(0^2+2^2)=2$
Error$g_1=(0,\,2)$, $\sigma'(z)=(0,\,1)$, $g_z=(0,\,2)$
Weights$\nabla_W\mathcal L=\begin{pmatrix}0\\2\end{pmatrix}\begin{pmatrix}1&2\end{pmatrix}=\begin{pmatrix}0&0\\2&4\end{pmatrix}$ (dead unit: zero row)
Input$g_0=g_zW=(2,\,2)$

Check: only unit 2 is active, so locally $\mathcal L=\tfrac12(x_1+x_2-1)^2$ and $\partial\mathcal L/\partial x_i=2$. ✓

Rank 1 per example

A column times a row has rank 1. A batch sums $B$ outer products (Four views of matrix multiplication), so the update has rank at most $B$.

$$ \nabla_{W_\ell}\mathcal L_{\text{batch}}=\frac1B\sum_{b=1}^B\delta_\ell^{(b)}h_{\ell-1}^{(b)T}=\frac1B\underbrace{\Delta_\ell}_{n_\ell\times B}\underbrace{H_{\ell-1}^T}_{B\times n_{\ell-1}}, \qquad \operatorname{rank}\le\min(B,\,n_\ell,\,n_{\ell-1}). $$

Columns of $\Delta_\ell$ are the $\delta_\ell^{(b)}$; columns of $H_{\ell-1}$ are the $h_{\ell-1}^{(b)}$.

Why backward, not forward

One loss, millions of weights. Starting from the single scalar at the end gives every gradient in one pass; starting from the inputs needs one pass per parameter.

Forward mode (JVP)$J\,v$one input direction per pass
Reverse mode (VJP): backprop$g\,J$one output per pass, so all of $\nabla\mathcal L$ at once

Cost: about $2\times$ the forward pass (per layer, one matmul for $g_{\ell-1}$, one for $\nabla_{W_\ell}$).

Derive it yourself

Two linear layers, no nonlinearity: $\mathcal L=\tfrac12\|W_2W_1x-y\|^2$. Use the recursion to show $\nabla_{W_1}\mathcal L=W_2^T\,r\,x^T$ with $r=W_2W_1x-y$. Check the shape.

Solution

$\sigma'=1$, so $g_{z_2}=g_2=r^T$. Then $g_1=r^TW_2$, $g_{z_1}=r^TW_2$, $\delta_1=W_2^Tr$, and $\nabla_{W_1}\mathcal L=\delta_1h_0^T=W_2^Trx^T$.

Shapes: $(n_1\times n_2)(n_2\times1)(1\times n_0)=n_1\times n_0$, the shape of $W_1$. ✓
