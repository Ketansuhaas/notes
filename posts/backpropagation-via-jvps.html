Backpropagation via Jacobian-vector products

Ketan Suhaas Saichandran
deep-learninggradientsbackpropagationjacobianrank

Builds on: Gradients, Jacobians, and Hessians, Matrix calculus with differentials · Leads to: Automatic differentiation, Weight initialization

Backprop is the chain rule evaluated right to left. Start from the loss's gradient (a row) and multiply by one small Jacobian per layer, never forming the full product.

Setup

Each layer is a linear map, then an elementwise squash. Two local Jacobians: $W_\ell$, and a diagonal (unit $i$ depends only on input $i$).

$$ h_0=x,\quad \underbrace{z_\ell}_{n_\ell\times1}=\underbrace{W_\ell}_{n_\ell\times n_{\ell-1}}\underbrace{h_{\ell-1}}_{n_{\ell-1}\times1}+b_\ell,\quad h_\ell=\sigma(z_\ell),\quad \text{loss } \mathcal L(h_L). $$

Read both Jacobians off entry by entry (entry $(i,j)$ is $\partial(\text{output}_i)/\partial(\text{input}_j)$):

$$z_{\ell,i}=\sum_jW_{\ell,ij}\,h_{\ell-1,j}+b_{\ell,i} \ \Rightarrow\ \frac{\partial z_{\ell,i}}{\partial h_{\ell-1,j}}=W_{\ell,ij},$$ $$h_{\ell,i}=\sigma(z_{\ell,i}) \ \Rightarrow\ \frac{\partial h_{\ell,i}}{\partial z_{\ell,j}}=\begin{cases}\sigma'(z_{\ell,i})&i=j\\0&i\ne j\ (\text{unit } i \text{ ignores } z_{\ell,j})\end{cases}$$

$$\Rightarrow\quad \frac{\partial z_\ell}{\partial h_{\ell-1}}=W_\ell, \qquad \frac{\partial h_\ell}{\partial z_\ell}=\operatorname{diag}\big(\sigma'(z_\ell)\big).$$

The backward recursion

$g_\ell=\partial\mathcal L/\partial h_\ell$ is a row: how much the loss cares about each unit. One step back means multiplying by that layer's two Jacobians, on the right.

$\mathcal L$ depends on $h_{\ell-1}$ only through $z_\ell$, then $h_\ell$. The chain rule multiplies the Jacobians along that path, and the shapes chain up:

$$\underbrace{g_{\ell-1}}_{1\times n_{\ell-1}}=\underbrace{\frac{\partial\mathcal L}{\partial h_\ell}}_{1\times n_\ell}\underbrace{\frac{\partial h_\ell}{\partial z_\ell}}_{n_\ell\times n_\ell}\underbrace{\frac{\partial z_\ell}{\partial h_{\ell-1}}}_{n_\ell\times n_{\ell-1}}$$ $$=g_\ell\,\operatorname{diag}\big(\sigma'(z_\ell)\big)\,W_\ell \quad\text{(previous section)}.$$

A row times a diagonal matrix scales each entry, $\big(g\operatorname{diag}(s)\big)_i=\sum_kg_k\,s_k\,[k=i]=g_i\,s_i$, so the first product is elementwise:

$$g_{z_\ell}:=\frac{\partial\mathcal L}{\partial z_\ell}=g_\ell\odot\sigma'(z_\ell)^T, \qquad \underbrace{g_{\ell-1}}_{1\times n_{\ell-1}}=\underbrace{g_{z_\ell}}_{1\times n_\ell}\underbrace{W_\ell}_{n_\ell\times n_{\ell-1}}.$$

Start: for $\mathcal L=\tfrac12\|h_L-y\|^2=\tfrac12\sum_i(h_{L,i}-y_i)^2$, each partial is $\partial\mathcal L/\partial h_{L,i}=h_{L,i}-y_i$, so $g_L=(h_L-y)^T$. Each step is a row times a matrix: a vector-Jacobian product.

Weight gradient: error times input

Exactly the linear layer from Matrix calculus: an outer product of the error arriving at $z_\ell$ and the input that fed it. An input that was $0$ gets no gradient on its weights.

Nudge only $W_\ell$ (its input $h_{\ell-1}$ is fixed). The differential of $z_\ell=W_\ell h_{\ell-1}+b_\ell$ is $dz_\ell=dW_\ell\,h_{\ell-1}$, and the loss changes by its row gradient times that:

$$d\mathcal L=\underbrace{g_{z_\ell}}_{1\times n_\ell}\,dz_\ell=g_{z_\ell}\,dW_\ell\,h_{\ell-1}$$ $$=\operatorname{tr}\big(g_{z_\ell}\,dW_\ell\,h_{\ell-1}\big)\quad\text{(a scalar is its own trace)}$$ $$=\operatorname{tr}\big(h_{\ell-1}\,g_{z_\ell}\,dW_\ell\big)\quad\text{(trace is cyclic)}.$$

The rule $d\mathcal L=\operatorname{tr}(G^TdW)\Rightarrow\nabla_W\mathcal L=G$ reads off $G^T=h_{\ell-1}g_{z_\ell}$. Write $\delta_\ell:=g_{z_\ell}^T$, the same error as a column:

$$\underbrace{\nabla_{W_\ell}\mathcal L}_{n_\ell\times n_{\ell-1}}=\big(h_{\ell-1}g_{z_\ell}\big)^T=\underbrace{\delta_\ell}_{n_\ell\times1}\underbrace{h_{\ell-1}^T}_{1\times n_{\ell-1}}.$$

Bias: $dz_\ell=db_\ell$, so $d\mathcal L=g_{z_\ell}\,db_\ell$ and $\nabla_{b_\ell}\mathcal L=\delta_\ell$. Entrywise check: $W_{\ell,ij}$ touches only $z_{\ell,i}$, with slope $h_{\ell-1,j}$, so $\partial\mathcal L/\partial W_{\ell,ij}=\delta_{\ell,i}\,h_{\ell-1,j}$, the $(i,j)$ entry of $\delta_\ell h_{\ell-1}^T$. ✓

Example: one ReLU layer

$x=\begin{pmatrix}1\\2\end{pmatrix}$, $W=\begin{pmatrix}1&-1\\1&1\end{pmatrix}$, $b=0$, $y=\begin{pmatrix}0\\1\end{pmatrix}$.

Forward$z=Wx=(1\cdot1-1\cdot2,\ 1\cdot1+1\cdot2)=(-1,\,3)$, $\ h=\max(z,0)=(0,\,3)$
Loss$h-y=(0,\,2)$, $\ \mathcal L=\tfrac12(0^2+2^2)=2$
Error$g_1=(h-y)^T=(0,\,2)$; ReLU$'$ is $0$ for $z\lt0$, $1$ for $z\gt0$: $\sigma'(z)=(0,\,1)$; $g_z=(0\cdot0,\ 2\cdot1)=(0,\,2)$
Weights$\nabla_W\mathcal L=\delta x^T=\begin{pmatrix}0\\2\end{pmatrix}\begin{pmatrix}1&2\end{pmatrix}=\begin{pmatrix}0\cdot1&0\cdot2\\2\cdot1&2\cdot2\end{pmatrix}=\begin{pmatrix}0&0\\2&4\end{pmatrix}$ (dead unit: zero row)
Input$g_0=g_zW=(0\cdot1+2\cdot1,\ 0\cdot(-1)+2\cdot1)=(2,\,2)$

Check: only unit 2 is active, so locally $\mathcal L=\tfrac12(W_{21}x_1+W_{22}x_2-1)^2$ with inner value $3-1=2$. Then $\partial\mathcal L/\partial x_i=2\cdot W_{2i}=(2,2)$ and $\partial\mathcal L/\partial W_{2i}=2\cdot x_i=(2,4)$. ✓

Rank 1 per example

A column times a row has rank 1. A batch sums $B$ outer products (Four views of matrix multiplication), so the update has rank at most $B$.

Rank 1. Every column of $\delta h^T$ is $\delta$ times a number: column $j$ is $h_j\,\delta$. So all columns lie on the line through $\delta$, and the rank is at most $1$.

The batch. The batch loss is the average $\mathcal L_{\text{batch}}=\frac1B\sum_b\mathcal L^{(b)}$, and the gradient is linear, so it averages the per-example outer products. Stack $\delta_\ell^{(b)}$ as the columns of $\Delta_\ell$ and $h_{\ell-1}^{(b)}$ as the columns of $H_{\ell-1}$; view 4 of matrix multiplication (column $b$ of $\Delta_\ell$ times row $b$ of $H_{\ell-1}^T$, summed over $b$) packs the sum into one matmul:

$$\nabla_{W_\ell}\mathcal L_{\text{batch}}=\frac1B\sum_{b=1}^B\nabla_{W_\ell}\mathcal L^{(b)}=\frac1B\sum_{b=1}^B\delta_\ell^{(b)}h_{\ell-1}^{(b)T}$$ $$=\frac1B\underbrace{\Delta_\ell}_{n_\ell\times B}\underbrace{H_{\ell-1}^T}_{B\times n_{\ell-1}}.$$

Rank is subadditive, $\operatorname{rank}(A+B)\le\operatorname{rank}A+\operatorname{rank}B$ (the column space of a sum sits inside the span of both column spaces), and a matrix's rank never exceeds either dimension, so

$$\operatorname{rank}\nabla_{W_\ell}\mathcal L_{\text{batch}}\le\min(B,\,n_\ell,\,n_{\ell-1}).$$

Why backward, not forward

One loss, millions of weights. Starting from the single scalar at the end gives every gradient in one pass; starting from the inputs needs one pass per parameter.

The full gradient is a product of Jacobians. Matrix products are associative, so we may choose where to start:

$$\underbrace{\nabla\mathcal L}_{1\times n_0}=\underbrace{g_L}_{1\times n_L}J_L\,J_{L-1}\cdots J_1, \qquad J_\ell=\operatorname{diag}(\sigma'(z_\ell))\,W_\ell.$$

OrderEach stepPasses for all of $\nabla\mathcal L$
Reverse (VJP): $\big((g_LJ_L)J_{L-1}\big)\cdots$row times matrix, $\approx n^2$ ops$1$: the row already holds every partial
Forward (JVP): $J_L\big(\cdots(J_1v)\big)$matrix times column, $\approx n^2$ opsone per input direction $v=e_k$: $n_0$ passes, each giving one partial $\nabla\mathcal L\,e_k$

(For weights, "input" means every parameter: $10^9$ forward passes versus $1$ reverse pass.) Automatic differentiation generalizes this to any graph.

Cost of one reverse pass. Count multiply-adds per layer, for a batch of $B$:

Forward$Z_\ell=W_\ell H_{\ell-1}$$n_\ell\,n_{\ell-1}\,B$
Backward, to the input$G_{\ell-1}=G_{z_\ell}W_\ell$$n_\ell\,n_{\ell-1}\,B$
Backward, to the weights$\Delta_\ell H_{\ell-1}^T$$n_\ell\,n_{\ell-1}\,B$

So the backward pass costs about $2\times$ the forward pass (the elementwise $\odot\sigma'$ is only $n_\ell B$), and a full training step about $3\times$.

Derive it yourself

Two linear layers, no nonlinearity: $\mathcal L=\tfrac12\|W_2W_1x-y\|^2$. Use the recursion to show $\nabla_{W_1}\mathcal L=W_2^T\,r\,x^T$ with $r=W_2W_1x-y$. Check the shape.

Solution

Here $\sigma(z)=z$, so $\sigma'=1$ and every $\odot\sigma'$ step does nothing. Run the recursion from the top:

$$h_2=W_2W_1x \ \Rightarrow\ g_2=(h_2-y)^T=r^T, \qquad g_{z_2}=g_2\odot1=r^T,$$ $$g_1=g_{z_2}W_2=r^TW_2, \qquad g_{z_1}=g_1\odot1=r^TW_2,$$ $$\delta_1=g_{z_1}^T=(r^TW_2)^T=W_2^Tr \ \Rightarrow\ \nabla_{W_1}\mathcal L=\delta_1h_0^T=W_2^Tr\,x^T.$$

Shapes: $(n_1\times n_2)(n_2\times1)(1\times n_0)=n_1\times n_0$, the shape of $W_1$. ✓
