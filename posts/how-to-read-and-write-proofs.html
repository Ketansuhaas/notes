Reading and writing proofs

Ketan Suhaas Saichandran

Builds on: Notation survival guide · Leads to: The derivation toolkit

A proof is a chain from what you know to what you want. Every link is a definition, an earlier result, or an algebra step, so you can check every link without being clever.

What a proof is

Reading a proof means asking of each line: which of the three kinds of link justifies it? If none does, that line is the gap.

linkwhat it saysexample
definitionunfold a word into its meaning$A\succ0$ means $x^TAx\gt0$ for all $x\ne0$
earlier resultcite something already provedspectral theorem: $A=Q\Lambda Q^T$
algebraa valid manipulationmultiply both sides by $v^T$

Direct proof

Start from what you know and walk forward until you reach what you want.

Claim 1. $A^TA$ is symmetric for any $A$. Want: $(A^TA)^T=A^TA$.

$$(A^TA)^T=A^T(A^T)^T \quad(\text{transpose of a product reverses: } (BC)^T=C^TB^T)$$ $$=A^TA \quad(\text{transposing twice gives back } A).\qquad\square$$

Claim 2. $\operatorname{Var}X\ge0$. Want: a nonnegative number.

$$\operatorname{Var}X=\mathbb{E}\big[(X-\mu)^2\big] \quad(\text{definition, } \mu=\mathbb{E}X)$$ $$(X-\mu)^2\ge0 \text{ for every outcome} \quad(\text{a square})$$ $$\Rightarrow\ \mathbb{E}\big[(X-\mu)^2\big]\ge0 \quad(\text{an average of nonnegative numbers}).\qquad\square$$

If and only if

"$P$ iff $Q$" is two claims glued together, $P\Rightarrow Q$ and $Q\Rightarrow P$. Prove each separately. Set equality $S=T$ works the same way: $S\subseteq T$ and $T\subseteq S$.

Claim. Symmetric $A$ is positive definite iff all its eigenvalues are $\gt0$.

($\Rightarrow$) Done in the figure: $Av=\lambda v$, $v\ne0$ gives $\lambda\|v\|^2=v^TAv\gt0$, so $\lambda\gt0$.

($\Leftarrow$) Take any $x\ne0$. By the spectral theorem $A=Q\Lambda Q^T$; set $y=Q^Tx$.

$$x^TAx=x^TQ\Lambda Q^Tx=y^T\Lambda y=\textstyle\sum_i\lambda_iy_i^2.$$

$Q$ is invertible, so $y\ne0$: some $y_i^2\gt0$. Every term is $\ge0$ and that one is $\gt0$ (as $\lambda_i\gt0$), so $x^TAx\gt0$. $\square$

Contrapositive

"$P\Rightarrow Q$" says exactly the same as "not $Q$ $\Rightarrow$ not $P$". Use it when "not $Q$" hands you something concrete to work with.

statement$P\Rightarrow Q$same as the original?
contrapositivenot $Q\Rightarrow$ not $P$yes, always
converse$Q\Rightarrow P$no, a different claim

Claim. If $A^TA$ is invertible, then the columns of $A$ are independent.

Contrapositive: if the columns are dependent, $A^TA$ is not invertible. Dependent columns hand us an $x\ne0$ with $Ax=0$ (definition of dependence). Then

$$A^TAx=A^T(Ax)=A^T0=0, \quad x\ne0,$$

so $A^TA$ sends a nonzero vector to $0$ and cannot be invertible. $\square$

Contradiction

Assume the claim is false and follow the consequences until two of them clash. Then the assumption was impossible.

Claim. Eigenvectors $v_1,v_2$ with distinct eigenvalues $\lambda_1\ne\lambda_2$ are independent.

Suppose not. Then $v_2=cv_1$ for some $c$, and $c\ne0$ because eigenvectors are nonzero. Apply $A$ to both sides:

$$Av_2=cAv_1 \ \Rightarrow\ \lambda_2v_2=c\lambda_1v_1=\lambda_1(cv_1)=\lambda_1v_2$$ $$\Rightarrow\ (\lambda_2-\lambda_1)\,v_2=0.$$

$v_2\ne0$, so $\lambda_2=\lambda_1$. That contradicts $\lambda_1\ne\lambda_2$. $\square$

Induction

To prove a claim for every $k=1,2,3,\dots$: prove it for $k=1$, then show "true for $k$" forces "true for $k+1$". Like dominoes.

Claim. If $Av=\lambda v$ then $A^kv=\lambda^kv$ for all $k\ge1$.

Base ($k=1$): $Av=\lambda v$ is the hypothesis. Step: assume $A^kv=\lambda^kv$. Then

$$A^{k+1}v=A(A^kv)=A(\lambda^kv) \quad(\text{assumption})$$ $$=\lambda^kAv=\lambda^k\cdot\lambda v=\lambda^{k+1}v \quad(\text{linearity, then base}).\qquad\square$$

Example

$A=\begin{pmatrix}2&1\\1&2\end{pmatrix}$, $v=(1,1)$, $\lambda=3$: $Av=(3,3)$, $A^2v=A(3,3)=(6+3,\,3+6)=(9,9)=3^2v$. ✓

Counterexample

A "for all" claim dies from a single case where it fails. No proof needed, just the case, checked.

Claim (false). For every square $A$, $\operatorname{rank}A=$ number of nonzero eigenvalues.

$$A=\begin{pmatrix}0&1\\0&0\end{pmatrix}: \quad \det(A-\lambda I)=\det\begin{pmatrix}-\lambda&1\\0&-\lambda\end{pmatrix}=\lambda^2.$$

Eigenvalues $0,0$: zero nonzero eigenvalues. Columns $(0,0)$ and $(1,0)$: rank $1$. Since $1\ne0$, the claim is false. (It holds for diagonalizable $A$; see defectiveness.)

Proof language

Each stock phrase is a promise. Know what you owe when you write it.

phrasewhat it commits you to
"Let $x$ be arbitrary"proving a "for all": use nothing about $x$ beyond its stated properties
"WLOG" (without loss of generality)the other cases are the same up to relabeling or symmetry; you must be sure they are
"It suffices to show $S$"$S$ implies the goal (that must be clear), and now you owe only $S$
"For all $\varepsilon\gt0$ there exists $N$"the reader picks $\varepsilon$ first; you must produce an $N$, which may depend on $\varepsilon$
"Suppose not"a contradiction proof begins; you must reach a false statement
"iff", $\iff$two proofs: $\Rightarrow$ and $\Leftarrow$
$\square$ (or QED)everything claimed has now been shown

Example: an $\varepsilon$-$N$ proof that $1/n\to0$

Given $\varepsilon\gt0$, choose $N\gt1/\varepsilon$. Then for $n\ge N$: $\ |1/n-0|=1/n\le1/N\lt\varepsilon$. $\square$ (For $\varepsilon=0.01$: $N=101$ works.)

Writing your own: a checklist

Most stuck proofs are stuck because the goal or the hypotheses were never written down in symbols.

1. State what you wantin symbols, unfolded to definitions
2. List what you knowhypotheses and their definitions, also in symbols
3. Name the key stepthe one move that connects 2 to 1
4. Check each linedefinition, earlier result, or algebra?

Example: positive definite $A$ is invertible

1. Want: $Ax=0\Rightarrow x=0$.  2. Know: $x^TAx\gt0$ for $x\ne0$.  3. Key step: hit $Ax=0$ with $x^T$.  4. Write it:

$$Ax=0 \ \Rightarrow\ x^TAx=x^T0=0 \ \Rightarrow\ x=0 \quad(\text{else } x^TAx\gt0).\qquad\square$$

Derive it yourself

Prove $N(A^TA)=N(A)$, where $N(M)=\{x: Mx=0\}$. It is a set equality, so prove both inclusions. Then conclude $\operatorname{rank}(A^TA)=\operatorname{rank}A$.

Solution

Want: $N(A)\subseteq N(A^TA)$ and $N(A^TA)\subseteq N(A)$.

($\subseteq$, easy direction) Let $x\in N(A)$, so $Ax=0$. Then $A^TAx=A^T(Ax)=A^T0=0$, so $x\in N(A^TA)$.

($\supseteq$, key step: turn the vector equation into a length) Let $x\in N(A^TA)$, so $A^TAx=0$. Multiply by $x^T$:

$$0=x^TA^TAx=(Ax)^T(Ax)=\|Ax\|^2.$$

A vector of length $0$ is $0$, so $Ax=0$ and $x\in N(A)$. $\square$

Rank. Both matrices have $n$ columns, so by rank-nullity $\operatorname{rank}=n-\dim N$, and the null spaces are equal. Check: $A=\begin{pmatrix}1&2\\2&4\end{pmatrix}$ has $A^TA=\begin{pmatrix}5&10\\10&20\end{pmatrix}$; both send $(2,-1)$ to $0$, both have rank $1$.
