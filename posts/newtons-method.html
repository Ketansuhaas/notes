Newton's method

Ketan Suhaas Saichandran
optimizationnewtonhessianconvergencesecond-order

Builds on: Taylor expansion in many variables, Momentum and Nesterov acceleration · Leads to: Stochastic gradient descent: noise and step sizes

Gradient descent knows only the slope, so it has to guess a step size. Newton also uses the curvature and jumps straight to the bottom of the local bowl. Near a minimum, the number of correct digits doubles every step.

The step: jump to the bottom of the local bowl

Replace $f$ near $x_k$ by its second-order Taylor model, and move to that model's minimum.

$$f(x_k+\Delta)\approx m(\Delta)=f(x_k)+\nabla f(x_k)^T\Delta+\tfrac12\Delta^TH_k\Delta,\qquad H_k=\nabla^2f(x_k).$$

Set the gradient of the model to zero ($\nabla_\Delta(b^T\Delta)=b$, $\nabla_\Delta(\tfrac12\Delta^TH\Delta)=H\Delta$ for symmetric $H$, matrix calculus):

$$\nabla m(\Delta)=\nabla f(x_k)+H_k\Delta=0\ \Rightarrow\ \boxed{\ \Delta=-H_k^{-1}\nabla f(x_k)\ }$$

If $H_k\succ0$ the model is a bowl, so this is its minimum. GD uses one number $\eta$; Newton uses $H_k^{-1}$, a step size per curvature direction.

Example

$f(x)=e^x-2x$ at $x_0=0$: $f'(0)=1-2=-1$, $f''(0)=e^0=1$, so $m(\Delta)=1-\Delta+\tfrac12\Delta^2$ and $\Delta=-\frac{-1}{1}=1$: $x_1=1$. The true minimum is $x^*=\ln2\approx0.693$ ($f'=e^x-2=0$).

Quadratics: one step

If $f$ is itself a quadratic, the Taylor model is exact, so its minimum is the true minimum.

Running example $f=\tfrac12x^TAx$, $A=\begin{pmatrix}2&1\\1&2\end{pmatrix}$: $\nabla f=Ax$, $H=A$, so $x_1=x_0-A^{-1}Ax_0=0$ from any start. From $x_0=(4,0)$:

$$\nabla f=\begin{pmatrix}2\cdot4+0\\4+2\cdot0\end{pmatrix}=\begin{pmatrix}8\\4\end{pmatrix},\qquad A^{-1}=\frac1{4-1}\begin{pmatrix}2&-1\\-1&2\end{pmatrix}\ \ (\text{swap, negate, divide by }\det),$$

$$A^{-1}\nabla f=\tfrac13\begin{pmatrix}16-4\\-8+8\end{pmatrix}=\begin{pmatrix}4\\0\end{pmatrix}\ \Rightarrow\ x_1=\begin{pmatrix}4\\0\end{pmatrix}-\begin{pmatrix}4\\0\end{pmatrix}=0.\ \checkmark$$

One step, whatever $\kappa$ is. GD at its best needs about $3.3$ steps per digit here, and $115$ when $\kappa=100$.

Why $\kappa$ disappears: Newton is GD in the right coordinates

Stretch space so the bowl becomes round. There the Hessian is $I$, $\kappa=1$, and plain GD with $\eta=1$ is exact. Mapped back, that GD step is the Newton step.

Let $x=A^{-1/2}y$ ($A^{1/2}=Q\Lambda^{1/2}Q^T$ exists by the spectral theorem, and is symmetric). Then

$$g(y)=f(A^{-1/2}y)=\tfrac12y^TA^{-1/2}AA^{-1/2}y=\tfrac12y^Ty,\qquad\nabla^2g=I.$$

GD with $\eta=1$ on $g$, using the chain rule $\nabla g(y)=A^{-1/2}\nabla f(x)$, then multiply by $A^{-1/2}$ to return to $x$:

$$y\leftarrow y-A^{-1/2}\nabla f(x)\ \Rightarrow\ x\leftarrow x-A^{-1}\nabla f(x).\quad\text{Newton.}$$

Affine invariance. For any invertible $B$, let $x=By$, $g(y)=f(By)$. Then $\nabla g=B^T\nabla f$ and $\nabla^2g=B^THB$, so Newton in $y$ gives

$$\Delta y=-(B^THB)^{-1}B^T\nabla f=-B^{-1}H^{-1}B^{-T}B^T\nabla f=-B^{-1}H^{-1}\nabla f\ \Rightarrow\ B\Delta y=\Delta x.$$

Same steps in every coordinate system. GD gives $B\Delta y=-\eta BB^T\nabla f$, which changes with $B$; $\kappa$ measures exactly this coordinate-dependence.

Local quadratic convergence

Near $x^*$ the Taylor model is nearly exact, and its error is second order, so the distance to $x^*$ gets squared each step.

Assume near $x^*$: $H(x)\succeq\mu I$, and the Hessian changes slowly, $\|H(x)-H(z)\|\le M\|x-z\|$. Want $e_{k+1}\le\frac{M}{2\mu}e_k^2$, where $e_k=\|x_k-x^*\|$.

1. Error after one step. Subtract $x^*$ and insert $\nabla f(x^*)=0$:

$$x_{k+1}-x^*=x_k-x^*-H_k^{-1}\big(\nabla f(x_k)-\nabla f(x^*)\big)$$

$$=H_k^{-1}\Big[H_k(x_k-x^*)-\big(\nabla f(x_k)-\nabla f(x^*)\big)\Big].$$

2. Gradient difference as an integral. Along $x(t)=x^*+t(x_k-x^*)$, $\frac{d}{dt}\nabla f(x(t))=H(x(t))\,(x_k-x^*)$ (chain rule). Fundamental theorem of calculus from $t=0$ to $1$:

$$\nabla f(x_k)-\nabla f(x^*)=\int_0^1H(x(t))\,(x_k-x^*)\,dt.$$

3. Combine. Write $H_k=\int_0^1H_k\,dt$, so the bracket is

$$\int_0^1\big(H_k-H(x(t))\big)(x_k-x^*)\,dt.$$

4. Bound. $\|x_k-x(t)\|=(1-t)e_k$, so the Lipschitz assumption gives

$$\|\text{bracket}\|\le\int_0^1M(1-t)e_k\cdot e_k\,dt=Me_k^2\int_0^1(1-t)\,dt=\frac M2e_k^2.$$

5. Undo $H_k^{-1}$. The eigenvalues of $H_k$ are $\ge\mu$, so those of $H_k^{-1}$ are $\le\frac1\mu$, and $\|H_k^{-1}v\|\le\frac1\mu\|v\|$:

$$\boxed{\ e_{k+1}\le\frac{M}{2\mu}\,e_k^2\ }$$

Digits double. Let $q_k=\frac M{2\mu}e_k$. Multiply the box by $\frac M{2\mu}$: $q_{k+1}\le q_k^2$, so $q_k\le q_0^{2^k}$. If $q_0=0.1$: $10^{-2},10^{-4},10^{-8},10^{-16}$. "Near" means $q_0\lt1$; then $e_k$ only shrinks, so the iterates stay where the assumptions hold.

The catch: cost and reach

Newton needs the whole $n\times n$ Hessian and a linear solve every step. For a network that is hopeless.

Solving $H\Delta=-\nabla f$ by elimination: for each of $n$ pivots, update up to $n\times n$ entries, so about $n\cdot n^2=n^3$ operations. With $n=10^8$ parameters:

GDNewton
memory (fp32)$4\cdot10^8$ B $=0.4$ GB$n^2=10^{16}$ entries $\times4$ B $=40$ PB
work per step$\sim n$$n^3=10^{24}$; at roughly $10^{15}$ FLOP/s (one H100, BF16 dense) $\approx10^9$ s $\approx30$ years

Reach: far from $x^*$ the model can mislead. Where $H$ has a negative eigenvalue (nonconvex), $-H^{-1}\nabla f$ heads uphill along it, toward a saddle or maximum; even convex $f$ can be overshot (see the exercise). Damped steps $x-\alpha H^{-1}\nabla f$ with a line search, or trust regions, fix this.

Practical methods keep the idea "a step size per direction" but approximate $H^{-1}$ cheaply: Adam uses a diagonal scaling ($O(n)$, built from gradient sizes rather than curvature), L-BFGS a low-rank estimate from recent gradients.

Derive it yourself

$f(x)=x-\log x$ for $x\gt0$. Find $x^*$ and the Newton update, show $e_{k+1}=e_k^2$ exactly for $e_k=1-x_k$, list the iterates from $x_0=0.5$, and find which $x_0$ converge. What happens from $x_0=3$?

Solution

$f'(x)=1-\frac1x=0\Rightarrow x^*=1$, and $f''(x)=\frac1{x^2}\gt0$ (a minimum). Newton:

$$x_{k+1}=x_k-\frac{1-1/x_k}{1/x_k^2}=x_k-(x_k^2-x_k)=2x_k-x_k^2.$$

$$1-x_{k+1}=1-2x_k+x_k^2=(1-x_k)^2\ \Rightarrow\ e_{k+1}=e_k^2.$$

From $x_0=0.5$: $e_k=0.5,\ 0.25,\ 0.0625,\ 0.0039,\ 1.5\times10^{-5}$, i.e. $x_k=0.5,\ 0.75,\ 0.9375,\ 0.99609,\ 0.9999847$. Matches the theorem: $|f'''(1)|=|-2/1^3|=2$, $f''(1)=1$, so $\frac M{2\mu}\approx1$.

$e_k=e_0^{2^k}\to0$ exactly when $|e_0|\lt1$, i.e. $0\lt x_0\lt2$. From $x_0=2$: $x_1=0$, off the domain. From $x_0=3$: $x_1=6-9=-3$, where $\log x$ is undefined. Quadratic convergence is a local promise.
