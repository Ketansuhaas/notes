Automatic differentiation

Ketan Suhaas Saichandran
deep-learninggradientsautomatic-differentiationjacobianbackpropagation

Builds on: Backpropagation via JVPs, Gradients, Jacobians, and Hessians · Leads to: The reparameterization trick

Backprop is one case of a general machine. Write any program as a graph of simple operations, then push derivatives through it: forward along with the values, or backward from the output.

The computation graph

Every program is a list of elementary operations. Each value is computed from earlier ones (its parents) by a function whose local derivative is known.

$$v_i=f_i\big(v_j:\ j\in\operatorname{pa}(i)\big), \qquad \text{local derivatives } \frac{\partial v_i}{\partial v_j}.$$

Running example: $y=x^2+x$

$v_1=x,\quad v_2=v_1\cdot v_1,\quad v_3=v_2+v_1=y$. The input is used twice.

Forward mode: tangents ride along

Pick an input direction and carry each value's rate of change next to the value, in the order the program runs.

$$\dot v_i=\sum_{j\in\operatorname{pa}(i)}\frac{\partial v_i}{\partial v_j}\,\dot v_j, \qquad \text{seed } \dot x=v\ \Rightarrow\ \text{one sweep gives } Jv \text{ (one column of } J).$$

Example at $x=3$, $\dot x=1$

$v_1=3$$\dot v_1=1$
$v_2=9$$\dot v_2=2v_1\dot v_1=6$
$v_3=12$$\dot v_3=\dot v_2+\dot v_1=7$

$dy/dx=2x+1=7$. ✓

Reverse mode: adjoints flow back

Run the program and store every value. Then ask each node how much the output cares about it, in reverse order. A value used twice collects from both uses.

$$\bar v_j=\frac{\partial y}{\partial v_j}=\sum_{i:\ j\in\operatorname{pa}(i)}\bar v_i\,\frac{\partial v_i}{\partial v_j},$$ $$\text{seed } \bar y=1\ \Rightarrow\ \text{one sweep gives the whole gradient (one row of } J).$$

Example at $x=3$

$\bar v_3=1$
$\bar v_2=\bar v_3\cdot1=1$
$\bar v_1=\bar v_3\cdot1+\bar v_2\cdot2v_1=1+6=7$two children, two terms

The local derivative $2v_1$ needs the stored forward value: reverse mode is two passes and must keep activations (training's memory cost).

Backprop is this on a chain: one child per node, so the sum has one term, and $\bar v$ is the row $g$ in $g_{\ell-1}=g_{z_\ell}W_\ell$.

Cost: pick the smaller side

A full Jacobian takes one sweep per input (forward) or one per output (reverse). Run the mode whose side is smaller.

Example

Loss of a $10^9$-parameter model: $n_{\text{out}}=1$. Reverse: $1$ sweep. Forward: $10^9$.

Derive it yourself

$y=x_1x_2+\sin x_1$. Write the graph, run one reverse sweep, and read off both $\partial y/\partial x_1$ and $\partial y/\partial x_2$.

Solution

$v_3=x_1x_2$, $v_4=\sin x_1$, $y=v_3+v_4$. Seed: $\bar v_3=\bar v_4=1$.

$\bar x_2=\bar v_3\,x_1=x_1$. $\ \bar x_1=\bar v_3\,x_2+\bar v_4\cos x_1=x_2+\cos x_1$ ($x_1$ has two children, so two terms). One sweep, both partials.
